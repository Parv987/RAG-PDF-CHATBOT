# RAG PDF Chatbot
## Adding PDFs to the Project

1. Create a new folder named **DATA** in the project directory.
2. Place the PDF file(s) you want to use inside the **DATA** folder.
3. If you are using only one PDF, no changes are required.
4. If you plan to use multiple PDFs:
   - Open the `pdf_loader.py` file.
   - Uncomment the section of code provided for handling multiple PDFs.
   - Adjust it as needed to ensure all PDFs in the **DATA** folder are loaded correctly.
